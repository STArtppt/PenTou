# PenTou 发布说明

按版本倒序记录面向用户的变更摘要（特性 / 修复 / 文档 / 破坏性变更）。  
完整提交历史以 git 为准；本文件只保留「发版时值得对外说」的条目。

---

## 如何更新本文件（给 Agent / 协作者）

当用户说类似：

> **「我准备发 v0.x.x 了，帮我更新 releases.md」**

按下面流程更新，**不要**在没被要求时擅自改 `package.json` 版本或打 tag / push：

1. **确认版本号**  
   以用户口述的 `vX.Y.Z` 为准（可带或不带 `v` 前缀；本文件标题统一写 `## vX.Y.Z`）。

2. **划定变更范围**  
   - 优先：`git log <上一版 tag 或上一节版本>..HEAD --oneline`  
   - 辅以：`openspec/changes/` 已落地任务、`src/docs/features/*/implementation-log.md`、未提交 diff  
   - 若仓库尚无对应 tag，以上一节 `## v…` 为下界，或问用户「从上个发布点算起」。

3. **筛选口径（写入用户可读摘要，不堆 commit 列表）**  
   - **新特性**：用户能感知的能力  
   - **修复**：影响使用路径的 bug  
   - **文档**：对外指南、README 叙事级更新  
   - **维护 / 内部**：仅当影响安装、部署、兼容时写一句；纯工程重构可省略  
   - 跳过：仅规划未落地、仅测试基建、仅私有 data/

4. **写入格式**（插在「版本记录」最上方）：

   ```markdown
   ## vX.Y.Z

   > 发布日期：YYYY-MM-DD（未知可写「待发布」）

   ### 新特性
   - …

   ### 修复
   - …

   ### 文档
   - …

   ### 说明（可选）
   - 升级注意 / 已知限制 / 迁移提示
   ```

   无某类变更时**省略该小节**，不要留空标题。

5. **交叉链接**  
   新能力若已有用户指南，链到 `docs/` 下对应文件（如 `cli-doc-push-guide.md`）。

6. **不要做的事**  
   - 不自动 `npm publish` / `git tag` / `git push`（除非用户另嘱）  
   - 不把本文件写成内部 implementation-log 的拷贝  
   - 不改写历史版本条目的事实（纠错可另起一行勘误）

## 版本记录

## v0.0.6

> 发布日期：待发布

### 新特性

- **CLI 文档推送与文档项目维度**：把项目目录里的 Markdown（README、设计文档、笔记等）推入文档平面；按 git 仓库（或 `--doc-project`）分组；支持 `push docs` 与登记 `--docs-dir` 后的 `pull` / `watch` 同步。详见 [cli-doc-push-guide.md](./cli-doc-push-guide.md)。
- **内容顶栏来源属性**：对话与文档顶栏统一为双行布局；对话展示品牌/形态、采集方式（网页 / 终端 / 手工）与可选项目徽章；文档展示「更新于」与来源三态（来自对话 / 来自终端 / 来自导入）。
- **用户向自动采集指南**：新增 [auto-collect-guide.md](./auto-collect-guide.md)，覆盖 CLI 采集器与浏览器插件的安装、排除规则与排障。

### 修复

- **一键迁移**漏搬 `document-projects.json`，迁移后文档项目维度不可见。
- **Grok CLI** 采集时间塌成入库时刻，恢复会话原始时间。
- **采集器路径**：对 `XDG_DATA_HOME` 与 exclude 中 `~` 的环境假设过强，导致部分机器漏采或排除失效。

### 文档

- README / 英文 README 强化「CLI 文档推送」「顶栏来源徽章」等卖点；产品介绍合并为单一 [pentou-introduction.md](./pentou-introduction.md)。
- 部署与扩展相关文档修订（含 MinerU 口径、Chrome Web Store 隐私政策入口等）。

### 说明

- 顶栏属性徽章目前为**桌面**路径；移动端仍由 MobileTopBar 承接标题，不展示完整徽章组。
- 一键迁移仍为 R1：大媒体库流式传输与中断续传后续补强。

## v0.0.5 及更早

`v0.0.1`–`v0.0.5` 的详细条目未在本文件回溯编写。大致能力基线包括：

- 本机 `npx` 一键启动、Docker 私有化、多源导入与 Ingest  
- CLI Collector / 浏览器插件自动采集  
- 全文与可选混合检索、文档闭环与 AI 侧边栏  
- UI 设计系统统一、手机端响应式浏览  
- 对外 README 用户视角改版与高可用叙事  

需要某一旧版的精确说明时，请查对应 git tag 的提交范围。
